# Accessibility acceptance contract

Target WCAG 2.2 AA. Verify 4.5:1 normal text, 3:1 large text, and 3:1 applicable non-text UI contrast. Verify keyboard navigation, focus visibility, accessible names, error identification, reflow/zoom, reduced motion, and status not communicated solely by color. Check all light/dark semantic foreground/background pairs and interactive states. Candidate palette is not approved until these tests pass. Store reproducible evidence and negative fixtures. Do not assume bronze text on white passes.
