# Evidence Record

## Evidence summary

WCAG 2.2 establishes accessibility requirements relevant to reusable interaction components, including dragging alternatives, target size, focus behavior, pointer cancellation, status communication, and robust name/role/value semantics.

## Exact claim supported or contradicted

Advanced design-system components cannot treat keyboard, target size, non-drag alternatives, focus, and semantic state as optional polish.

## Source provenance

Primary W3C Recommendation.

## Relevant excerpt or data

The requirements set uses WCAG 2.2 AA as the stable component baseline, including 2.5.7 Dragging Movements and 2.5.8 Target Size (Minimum).

## Interpretation

Direct manipulation features such as sliders, reordering, and split panes need discrete alternatives when dragging is not essential.

## Limitations

Component compliance does not establish whole-application compliance.

## Counterevidence

None material to using WCAG as the accessibility baseline.

## Reproduction or verification notes

Verify requirements against the current W3C WCAG 2.2 Recommendation and Understanding documents.
