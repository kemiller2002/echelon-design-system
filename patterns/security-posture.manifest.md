# Feature Manifest — security posture pattern

## Purpose
Present a Tutela release posture with immutable subject, scope, freshness and blockers without deriving or reinterpreting security state.

## Ownership
Tutela owns posture derivation. Forma owns accessible presentation only.

## States
PASS, CONDITIONAL, BLOCKED and INDETERMINATE. Text is mandatory; color is supplementary.

## Invariants
- Unknowns are not hidden below findings.
- No composite security score.
- Stable IDs remain linkable.
- Qualification that PASS is scoped evidence status remains available.
- Responsive reflow and print preserve subject/scope/blockers.

## Verification
Exercise all four states, keyboard navigation, screen reader naming, high contrast, zoom/reflow and mobile widths.
